2. What the software does on this computer

PRISM is a game performance and hardware tuning toolkit. In normal use it:

  · reads the models and sensor readings of the CPU, graphics card, motherboard, memory, disks and displays;
  · adjusts display colors or processes the game image in the selected mode when you enable display adjustment or game filters;
  · lets the installer check for the PawnIO hardware access driver and install it when the required version is missing.
    The driver is used to read low-level sensors; Windows may ask for administrator rights during installation;
  · adjusts Windows power plans, network and game-related system settings for "game optimization";
  · starts the bundled Intel PresentMon to capture game frame rates.

The parts that change system settings need administrator rights, and the program asks for them when needed.
Every tuning item states in the interface what it changes and whether it is restored automatically when turned off.


3. Data

Filter settings, hardware samples and performance reports are stored on this computer. Checking for a new version connects to the update service;
if you choose to update, the program downloads the installer.
When you export a report, you choose where it is saved and whom it is shared with.

6. Uninstalling

You can uninstall at any time in two ways:

  · find "PRISM" under Settings › Apps › Installed apps and click Uninstall;
  · or run PRISM Setup again and choose "Uninstall".

Uninstalling removes the program files and the Start menu and desktop shortcuts.
Your own settings and performance session records are kept in your user folder and are not deleted.

PawnIO is a separately installed driver and is kept after PRISM is uninstalled. If other software also uses the driver, check before uninstalling it separately.

二、本软件会对这台电脑做什么

PRISM是一套游戏性能与硬件调校工具，正常使用中会涉及以下操作：

  · 读取 CPU、显卡、主板、内存、硬盘、显示器的型号与传感器读数；
  · 在您启用显示调节或游戏滤镜时，按所选模式调整显示色彩或处理游戏画面；
  · 安装程序会检查 PawnIO 硬件访问驱动，缺少所需版本时一并安装。
    此驱动用于读取底层传感器，安装时 Windows 可能请求管理员权限。
  · 调整 Windows 的电源方案、网络与游戏相关系统设置，用于「游戏优化」；
  · 启动随附的 Intel PresentMon 采集游戏帧率。

其中修改系统设置的部分需要管理员权限，程序会在需要时向您申请。
每一项调校在界面上都写明了它改的是什么，以及关闭后是否自动还原。
